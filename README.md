# 바탕화면의 하데스 · hadesktop

Windows 바탕화면에 하데스 멤버가 나타나는 팬 앱입니다.
가볍게 바탕화면을 통해 캐릭터 별 다양한 인터렉션을 즐겨주세요.

## 다운로드

**[최신 버전 받기 →](https://github.com/cookie-j10/hadesktop/releases/latest)**

Windows x64용이며 실행에 필요한 .NET 런타임이 포함되어 있습니다. 설치판과 ZIP판 중 하나를 선택하세요.

| 선택 | Releases의 Assets에서 받을 파일 |
| --- | --- |
| 설치판 · 권장 | `CharacterView-Setup-버전.exe` |
| 설치 없는 ZIP판 | `CharacterView-v버전-win-x64.zip` |

`Source code (zip)`과 `Source code (tar.gz)`는 실행 파일이 아닙니다. `latest.json`과 `SHA256SUMS.txt`는 업데이트·파일 확인용이므로 따로 받을 필요가 없습니다.

## 설치와 첫 실행

- **설치판:** EXE 실행 → 자동 실행 여부 선택 → 설치 → 완료 화면에서 지금 실행을 선택하거나 시작 메뉴의 **바탕화면의 하데스**를 실행합니다. 로그인 자동 실행은 기본 꺼짐입니다.
- **ZIP판:** 원하는 폴더에 **전체 압축 해제**한 뒤 `CharacterView.App.exe`를 실행합니다. EXE만 따로 꺼내지 마세요.

처음에는 바탕화면에 캐릭터와 상자가 나타납니다. 다른 창이 덮고 있다면 바탕화면을 확인해 주세요. 트레이의 멤버 얼굴을 누르면 **멤버 / 설정 / 도움말**이 열립니다.

설정 창을 닫아도 계속 실행됩니다. 종료는 **트레이 우클릭 → 종료**입니다.

## 업데이트와 제거

설치판은 앱의 업데이트 확인 기능을 이용할 수 있습니다. 
ZIP판은 새 버전을 별도 폴더에 풀어 실행합니다. 직접 교체할 때에는 먼저 기존 앱을 종료하세요.

설치판 제거는 Windows **설정 → 앱 → 설치된 앱 → 바탕화면의 하데스 → 제거**, ZIP판 제거는 앱 종료 후 압축을 푼 폴더 삭제입니다. 멤버·크기·배치 설정은 `%LOCALAPPDATA%\CharacterView\settings.json`에 별도로 남습니다.

## 배포 안내

설치·업데이트·패키지 자동 검사를 진행했으며, 다양한 PC·모니터 배율과 장시간 사용은 계속 확인하고 있습니다. 실행 파일은 아직 코드 서명되지 않아 Windows 보안 경고가 표시될 수 있습니다.

현재 모션은 소리 없는 창작 연출입니다. 실제 음악·영상 앱 내용이나 바탕화면 아이콘을 감지하지 않습니다. 이곳은 팬 앱의 설치 파일과 사용 안내를 제공하는 배포 저장소입니다.
